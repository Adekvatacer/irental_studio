# IRENTAL Studio — демо-сайт

Демо-сайт для студії оренди одягу та готових образів. Каталог за колекціями, картка образу з розрахунком ціни (фотосесія / подія ×2), бронювання через Telegram, мови UA / EN / RU, динамічний фон і анімований логотип.

## Запуск

Статичний сайт без збірки: відкрийте `index.html` у браузері.

## Структура

- `index.html` — сторінка
- `assets/css/styles.css` — стилі
- `assets/js/` — `app.js` (каталог, картка, мови), `i18n.js` (переклади), `logo.js` + `logo-data.js` (анімований логотип), `bg.js` (фон), `data.js` (дані товарів)
- `products/` — фото товарів і `products.json` (джерело даних)
- `logo/index.html` — окрема сторінка з анімацією логотипу

## Дані товарів

Редагуються в `products/products.json`. Після змін скопіюйте вміст у `assets/js/data.js` у форматі `window.DATA = {...};`.
